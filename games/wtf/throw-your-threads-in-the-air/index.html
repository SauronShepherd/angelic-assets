About the local PySpark emulator and the evidence

The three labs use the JavaScript PySpark API emulator supplied with your material. It interprets a limited PySpark-like subset in this page. It does not run Python, Apache Spark, a JVM, a cluster, real worker processes, real threads, network I/O, races, or memory failures. Lab records are fictional evidence used to reason about results. Each technical case file links to primary documentation or the specific Spark issue; version and scope matter.

All scenes, character portraits, audio files, and soundtrack mapping live in the neighboring assets/ folder. Keep it beside this HTML file, or copy the whole folder into the other repository and preserve the relative paths.
